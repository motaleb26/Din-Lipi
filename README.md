# আমার দিনলিপি / My Daily Log

একটি অফলাইন অ্যাপ। সব তথ্য শুধু আপনার ফোনে থাকে। ভাষা: বাংলা ও English।
An offline app. All data stays on your phone. Languages: Bengali and English.

## ফোনে ইনস্টল করার উপায় / How to install

অ্যাপটি ইনস্টল করতে এই ফোল্ডারটি একবার ইন্টারনেটে (https) আপলোড করতে হয়। এরপর ফোনে ইনস্টল করলে ইন্টারনেট ছাড়াই চলবে।
The folder must be uploaded once to a free https host. After installing, it works without internet.

### GitHub Pages (ফ্রি)
1. github.com এ অ্যাকাউন্ট খুলুন, নতুন public repository বানান (নাম যেমন: dinlipi)।
2. "Add file" > "Upload files" দিয়ে এই ফোল্ডারের সব ফাইল আপলোড করুন (index.html সহ) এবং Commit করুন।
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, Folder: / (root) > Save।
4. ১-২ মিনিট পর https://আপনার-ইউজারনেম.github.io/dinlipi/ লিংক চালু হবে।
5. ফোনের Chrome-এ লিংকটি খুলুন > তিন ডটের মেনু > "Install app" বা "Add to Home screen"।

### Netlify (ফ্রি)
app.netlify.com/drop এ গিয়ে ফোল্ডারটি ড্র্যাগ করে ছেড়ে দিন। যে লিংক পাবেন সেটি ফোনের Chrome-এ খুলে একইভাবে ইনস্টল করুন।

## ব্যাকআপ / Backup
Settings > Backup থেকে মাঝে মাঝে ব্যাকআপ নিন। অ্যাপ মুছলে বা ব্রাউজার ডাটা পরিষ্কার করলে তথ্য চলে যেতে পারে।
Take backups now and then from Settings > Backup.

## আসল APK ফাইল চাইলে / If you want a real APK
হোস্ট করা লিংকটি https://www.pwabuilder.com এ দিয়ে "Package for stores" থেকে Android প্যাকেজ (APK) নামানো যায়।
